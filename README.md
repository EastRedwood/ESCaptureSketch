# ESCaptureSketch

Windows "캡처 및 스케치"의 업글판. 단축키로 화면을 캡처(사각형/창)하거나 빈 무한 화이트보드로 시작해 바로 스케치하고, 복사·저장합니다.
(WPF + SkiaSharp, net10)

Capture, sketch and share fast: a Windows tray tool with a transparent chalkboard, an endless whiteboard, layers and configurable shortcuts. The interface is available in Korean and English.

## 설치 / Install
1. [Releases](https://github.com/EastRedwood/ESCaptureSketch/releases)에서 `ESCaptureSketch-v…-win-x64.zip` 을 받아 원하는 폴더에 풉니다. / Download the zip from Releases and unzip it.
2. [.NET 10 데스크톱 런타임(x64)](https://dotnet.microsoft.com/download/dotnet/10.0)이 없으면 설치합니다. / Install the .NET 10 Desktop Runtime (x64) if you do not have it.
3. `ESCaptureSketch.exe` 를 실행합니다. `Ctrl+Shift+S` 로 캡처합니다. / Run it and press `Ctrl+Shift+S`.

- 서명하지 않은 프로그램이라 SmartScreen 경고가 뜰 수 있습니다(`추가 정보` > `실행`). / Not code-signed: SmartScreen may warn (`More info` > `Run anyway`).
- 처음 실행하면 자동 시작 여부를 묻고, `.escs` 파일을 연결합니다(설정에서 끌 수 있음). / Asks about autostart on first run and associates `.escs` files.
- 삭제: 트레이에서 종료 → `ESCaptureSketch-RemoveAutostart.bat`, `ESCaptureSketch-RemoveFileType.bat` 실행 → 폴더 삭제(설정은 `%AppData%\ESCaptureSketch`). / Uninstall: exit, run both `.bat` files, delete the folder.
- 사용 설명서: 트레이 우클릭 > `사용 설명서`. / Manual: tray icon > `User manual`.
- 만든 사람 / Author: EastRedwood · https://eastredwood.pages.dev/ · [커피 한잔 / Buy me a coffee](https://ko-fi.com/eastredwood)
- 배포 묶음 만들기(개발용): `powershell -ExecutionPolicy Bypass -File .\make-release.ps1` → `release\` 폴더.

## 사용
- 기본 단축키 `Ctrl+Shift+S`(설정 파일에서 변경) 또는 트레이 아이콘 좌클릭 → 상단 모드 바: `1 사각형`, `2 창`, `3 화이트보드`, `4 닫기` (클릭 또는 숫자 키). 현재 바에는 `1 사각형`, `2 창`, `3 전체화면`, `4 화이트보드`, `5 칠판`, `6 캡처 후 프로그램 열기`, `7 x초 후 전체화면`, 맨 끝의 `Esc 닫기`가 있습니다(닫기는 Esc 키 또는 클릭).
- **창(2)에서 모든 모니터 캡처**: 창 모드에서 마우스 커서를 주 화면의 왼쪽 위 끝 (0,0)에 두면 모든 모니터가 선택되고, 클릭하면 한 장으로 캡처합니다(모니터가 없는 빈 자리는 검게).
- **칠판(5)**: 커서가 있는 모니터 전체를 투명한 낙서판으로 덮습니다. 뒤의 화면이 그대로 보이고 그 위에 편집창과 같은 도구로 그립니다(확대·이동은 잠겨 있음). 도구 줄·오른쪽 패널만 불투명하고, `Esc` 또는 `닫기` 단추로 닫습니다. `Ctrl+Shift+B`(설정 > 단축키에서 변경, 칠판이 열려 있는 동안만 전역)를 누르면 그림은 화면에 남고 마우스는 아래 프로그램으로 통과하며(클릭 통과, 키보드 입력도 바로 아래 맨 위 창으로 넘어감), 다시 누르면 칠판이 앞으로 올라와 그리기가 돌아옵니다. 클릭 통과가 아닐 때 Alt+Tab 등으로 다른 프로그램을 고르면 그 창이 칠판 위로 올라오고, 칠판을 다시 고르면 위로 돌아옵니다. 클릭 통과 중에도 Alt+Tab 으로 고른 창은 칠판 위로 올라오고, 칠판을 다시 고르면 그림이 위에 남은 통과 상태로 돌아갑니다(클릭이나 작업 표시줄로 창을 바꾸면 그림은 계속 위에 있음). 설정(F10) 아래의 `최대화` 단추 또는 `F11`로 메뉴를 모두 숨기고(`복원` 단추만 남음) 다시 누르면 보입니다. 복사·저장은 칠판을 열 때의 모니터 화면 위에 낙서를 합쳐 한 장(모니터 해상도 그대로)으로 내보냅니다.
  - 사각형: 드래그하면 바로 캡처 / 창: 창 위에서 클릭하면 바로 캡처 / Esc·우클릭: 취소
- 편집창: 휠 = 커서 기준 확대·축소, 휠 누른 채 끌기 = 이동, 좌클릭 = 현재 도구, 우클릭 = 지우개(물체 단위), Shift+휠 = 선 굵기, Shift+끌기 = 직선·화살표 15° 단위/시작점 중심 정사각형·정원(블러 포함), 블러는 Ctrl+끌기 = 단색 상자
- 도구 기본 단축키: 볼펜 Ctrl+1, 형광펜 Ctrl+2, 선 Ctrl+3, 네모 Ctrl+4, 동그라미 Ctrl+5, 화살표 Alt+2 자르기 Ctrl+6, 레이저 포인터 Alt+1, 마커 Alt+5
- 이전/다음: Ctrl+Z / Ctrl+Y. 오른쪽 숫자 = 다음으로 갈 수 있는 개수. 숫자를 클릭해 입력하면 그 지점으로 이동, 숫자 위에서 휠 위 = 증가(이전으로 돌아감)/아래 = 감소.
- **끝단·핀**(끝단 Ctrl+마우스5, 핀 Ctrl+마우스4, 핀 번호 버튼은 앞에서부터 Shift+1~Shift+9 — 모두 설정 > 단축키에서 바꿀 수 있고, 칠판의 메뉴 숨기기 F11·칠판 닫기 Esc도 같습니다): `끝단` = 가장 높은 숫자(가장 최근 상태)로 이동. `핀` = 현재 번호를 기억하고 오른쪽에 그 번호가 적힌 버튼(예: 12)을 추가하며, 누르면 그 번호로 이동. 이전·다음·끝단·핀 버튼은 글자 없이 아이콘만 씁니다(우클릭 = 삭제). 새 창을 열면 초기화되고(0번 핀이 기본으로 들어 있음) 저장하지 않으며, 끝단 숫자가 핀 번호보다 작아지면 그 핀은 자동 삭제됩니다.
- **격자 다시 조절**: 레이어 목록에서 **격자 레이어를 클릭**하면(또는 레이어 선택 단축키로 들어가면) **선택 도구로 바뀌며 바로 편집 상태**(격자 레이어에서 나오면 쓰던 도구로 돌아감. 격자에 있는 동안 다른 도구를 골랐으면 그 도구 유지)가 되어 범위에 점선 상자와 네 꼭지점이 생깁니다. 꼭지점을 좌클릭으로 끌면 범위가 바뀌고(**Shift 는 칸이 잘리지 않는 크기**), 범위 안에서 휠 클릭 드래그하면 격자가 옮겨집니다. Ctrl+Z 로 되돌립니다. 칸 번호는 범위의 왼쪽 위를 따라갑니다. 이 편집 상태에서 **색을 고르면 격자 색이, 굵기(슬라이더·Shift+휠·굵기 단축키)를 바꾸면 격자 선 굵기**가 바뀝니다(도구함 불러오기는 바꾸지 않음). **격자 레이어를 고른 채 격자 범위를 우클릭(드래그)하면 그 격자 레이어가 삭제**되며 Ctrl+Z 로 되살립니다. 격자 레이어를 고른 채 그리기·글자·붙여넣기를 하면 바로 아래의 그림 레이어로 선택이 옮겨가 거기에 그려집니다.
- **쓴 글자 다시 편집**: 선택 도구로 범위를 끌어 **글자 하나만** 잡으면 선택 상태가 됩니다(복사·잘라내기·휠 클릭 드래그 이동 가능). 그 **글자 상자 위에 마우스를 올린 채 입력**하면 그때 글 커서가 나타나며 글 맨 끝에 이어 씁니다(Backspace 로 지우기, Ctrl+V 글자 붙여넣기도 같음). Enter·Esc·클릭으로 확정하고, 다 지우면 글자 삭제(Ctrl+Z 복원). 마우스가 상자 밖이면 입력은 커서 위치의 새 글자가 됩니다(설정 > 편집의 "커서 위치에 새 글자"를 따름).
- **물체 복사·붙여넣기**: 선택 도구로 고른 것(또는 편집 중인 것을 잘라낸 것)을 이 프로그램에 붙여넣으면 합친 그림이 아니라 **물체 하나하나**(글자·도형·마커·그림·블러, 크기·색 유지)로 보이는 화면 가운데에 놓이고, **선택 도구로 바뀌며 모두 선택된 상태**가 되어 상자 안 휠 클릭 드래그로 함께 옮깁니다. 글자는 다시 편집할 수 있습니다. 모두 지금 선택한 레이어에 들어갑니다. 다른 프로그램에는 그림 한 장으로 붙습니다. 글자를 쓰는 중에 붙여넣으면 글자 내용만 끼워 넣습니다.
- **입력 중 이전**: 글자를 쓰거나 다시 편집하는 중에 이전(Ctrl+Z·단추)을 누르면 입력을 확정한 뒤 그 입력을 되돌립니다(다음으로 되살릴 수 있음).
- **선택한 것의 크기**: 선택 도구로 고른 상자 위에서 **Shift+휠**(또는 굵기 단축키)을 쓰면 글자는 크기가, 선·화살표·네모·동그라미·마커는 굵기(크기)가 바뀝니다. 여러 개면 각자의 값에서 한 단계씩 바뀌며 Ctrl+Z 로 되돌립니다. 펜·형광펜·블러·붙여넣은 그림은 바뀌지 않습니다.
- **선택·편집은 지금 선택한 레이어만**: 선택 도구는 현재 레이어의 물체만 고릅니다(지우개와 같음). 레이어를 바꾸거나 현재 레이어를 숨기면 선택·편집 상태가 풀려, 다른 레이어의 그림·도형은 옮기거나 바꿀 수 없습니다. 그 레이어를 먼저 선택하십시오.
- **편집점(손잡이)**: 선·화살표는 양 끝, **네모·동그라미·블러 상자·붙여넣은 그림은 네 꼭지점**, 마커는 방향점을 좌클릭으로 끕니다. 그린 직후의 편집 상태뿐 아니라 **선택 도구(Tab)로 고른 물체에도** 보입니다(여러 개면 각각). 네모·동그라미·블러 상자는 기본이 대각선 꼭지점 고정, **Shift 를 누른 채 끌면 도형의 중심을 고정**하고 늘어납니다. 그림은 기본이 비율 유지, Shift 는 자유 비율입니다. 펜 선·형광펜·글자에는 편집점이 없습니다.
- **잘라내기(Ctrl+X)**: 선택 도구로 고른 물체들, 또는 편집 상태(파란 점선 상자)인 그림·도형·마커만 클립보드로 옮기고 지웁니다. 바탕 이미지와 고르지 않은 물체는 담지 않으며, 이전(Ctrl+Z)으로 되돌립니다. 이 프로그램에 다시 붙여넣으면 물체로 되살아나고(아래 "물체 복사·붙여넣기"), 다른 프로그램에는 바탕색에 얹은 그림이 들어갑니다(PNG 를 읽는 프로그램은 투명 유지). 키는 설정 > 단축키에서 바꿉니다.
- 복사(Ctrl+C): **글자 편집 중에 범위를 선택(Shift+방향키·Home·End, Ctrl+A)했으면 그 글자를**, **선택 도구로 고른 것이 있으면 그것만**(투명 처리는 잘라내기와 같음), 없으면 보이는 화면을 클립보드로 (그리자마자 생기는 편집 상태의 점선 상자는 고른 것으로 치지 않음). 위쪽 **복사 버튼**은 선택과 상관없이 늘 보이는 화면입니다.
- 저장(Ctrl+S) = PNG(기본)·JPG·`.escs` 파일로 저장 (아래 "저장").
- **색 고르기 창**(`사용자 지정 색…`): 기본 색 48개, 사용자 지정 색 16칸(`사용자 지정 색에 추가`로 저장), 색상 띠와 채도·명도 사각형, 새 색/현재 색 미리보기, **HEX 코드(#RRGGBB, 3자리도 가능)와 빨강·녹색·파랑(0~255) 입력칸**이 있습니다. 라이트·다크 테마를 따르고, 선택된 칸(현재색 또는 바탕색)에 적용됩니다.
- **현재색 · 바탕색**: 오른쪽 패널의 현재색 칸(색 목록 아래)과 바탕색 칸(마커 영역의 숫자 칸 오른쪽) 중 하나를 누르면 파란 테두리로 선택되고, 위 색 목록(사용자 지정 색 포함)에서 고른 색이 그 칸에 적용됩니다(색 코드 표시는 없음). 마커는 **현재색이 글자와 테두리 색, 바탕색이 원 안쪽 색**입니다. 바탕색의 기본은 자동(칸에 "자동" 표시, 우클릭으로 자동 복귀)이며, 자동이면 안쪽은 흰색이고 현재색이 밝으면(밝기 170 초과: 노랑·흰색 등) 검정입니다. 도구함에도 함께 저장되고 설정에 기억됩니다. 바탕색을 바꾸기 전에 찍은 마커는 그대로입니다.

- **사용 설명서**: 트레이 우클릭 `사용 설명서`, 설정 > 정보의 `사용 설명서 열기`, 우측 패널 아래 `자세한 설명서`로 설명서 창(왼쪽 목차, 오른쪽 본문)을 엽니다. 원본은 프로젝트의 `Manual.txt`(꾸밈 규칙: `1. 제목` 장, `[제목]` 소제목, `◆ 이름 (키)` 항목, `- ` 점 목록, `※ ` 알림 상자, `왼쪽 | 오른쪽` 표. 장과 소제목이 목차)이고, 빌드하면 실행 파일 옆에 `설명서.txt`로 함께 나갑니다. 창은 `설명서.txt`를 먼저 읽고, 없으면 실행 파일에 넣은 내용을 보여 줍니다.
- **칠판의 창 제어 단추**: 칠판 전체 화면(F11) 단추 바로 왼쪽의 `창 제어` 단추는(메뉴를 숨긴 동안에는 `복원` 단추 왼쪽, `복원` 단추를 끈 설정이면 오른쪽 끝) 클릭 통과 단축키(기본 Ctrl+Shift+B, 설정 > 단축키)와 같은 일을 합니다. 켜면 그림은 남고 마우스가 아래 창으로 가며 단추 바탕이 파란색이 됩니다. 통과 중에도 단추는 눌립니다. 글자는 설정 > 도구 줄 표시에 따라 이름 또는 단축키입니다. F11 로 메뉴를 숨겨도 남으며(이때는 `복원` 단추처럼 뒤가 비칩니다), 설정 > 일반 > 전체 화면에서 끌 수 있습니다(기본 켬).
- **전체 화면 단추**: 윗줄 맨 오른쪽 단추(일반 창은 설정 F10, 칠판은 닫기 Esc) 바로 아래의 `최대화`(F11) 단추. 칠판과 일반 창이 같은 단추를 씁니다(칠판은 최대화 대신 메뉴만 숨김). 숨긴 동안의 `복원` 단추는 **일반 창은 창의 오른쪽 위 끝**, **칠판은 둘째 줄 오른쪽 끝**(화면 맨 위의 다른 프로그램 닫기(X)와 겹치지 않게)에 남습니다. 설정 > 일반 > 전체 화면에서 이 복원 단추도 숨길 수 있습니다(F11 키로만 되돌림).
- **F11(일반 창)**: 창을 테두리(제목 표시줄) 없는 전체 화면으로 최대화하고(보던 화면의 배율과 중심은 그대로 두며, 화면에 맞추려면 Alt+3 — 전체 화면에서는 100% 를 넘겨 화면 가득 맞춥니다) 도구 줄·오른쪽 패널·도구함·상태 줄을 숨깁니다(오른쪽 위에 `보이기` 단추만 남음). 다시 F11(또는 `보이기`)을 누르면 원래 크기와 메뉴로 돌아옵니다. 칠판의 숨기기와 같은 단축키(설정 > 단축키 `메뉴 숨기기/보이기`)입니다. 이 상태에서 닫아도 저장되는 창 크기·최대화 여부는 들어가기 전 상태입니다.
- **스포이드**: 오른쪽 패널의 현재색 칸 옆과 `사용자 지정 색…` 창의 단추를 누르면, 그 순간의 모든 모니터 화면을 얼려 놓고 커서 옆 확대 보기(색 코드 표시)를 보며 클릭한 픽셀의 색을 가져옵니다(우클릭·Esc 취소). 이 프로그램 밖의 화면 색도 고를 수 있습니다. 패널에서 고르면 현재색이 바뀌고(편집 중인 글자·도형도 함께), 색 창에서 고르면 `새 색`에 들어가며 `확인`을 눌러야 적용됩니다.
- **격자 모양 번호**: 격자 모양은 오른쪽 패널의 **격자 · 행열 · 좌표** 세 버튼으로 고릅니다(**격자**: 줄만, **행열**: 바깥의 행 번호·열 글자 띠, **좌표**: 칸 안의 A1·B1 좌표만). 버튼은 **격자 도구를 쓸 때와 격자를 편집 중일 때만** 눌려 보입니다. 격자 편집 중에는 그 격자의 모양이 눌려 보이고 누르면 **그 격자의 모양이 바뀌며**(Ctrl+Z 가능), 그 밖에는 새로 만들 격자의 모양을 정하면서 격자 도구로 바뀝니다. 격자 도구를 고르면(Alt+4 단축키·도구 단추) 버튼에 **1~3** 이 뜨고 그 숫자 키로 고릅니다(끄는 방법은 마커 번호와 같음).
- **클립보드 이미지 띄우기(Win+Alt+V, 어디서나 / 트레이 메뉴)**: 클립보드의 이미지만 담은 테두리 없는 창을 항상 위로 띄웁니다(누를 때마다 새 창, 커서가 있는 모니터 가운데, 원래 크기이며 화면보다 크면 맞춰 줄임). **휠** 은 창 크기를 그대로 두고 안의 그림을 커서 기준으로 확대·축소(전체가 꽉 차는 크기가 최소, 32배까지), **휠 클릭** 은 휠 확대를 되돌림, **가장자리·모서리 좌클릭 드래그** 는 창 크기를 바꿔 그림을 함께 키우고 줄임(비율 유지), **휠 클릭 드래그**는 휠로 확대한 상태면 그림 이동·아니면 창 이동, 안쪽 좌클릭 드래그는 창 이동, **더블클릭**은 핀(항상 위) 켜기/끄기(바뀔 때 큰 반투명 핀·사선 핀 표시가 잠깐 뜨고, 핀을 끄면 작업 표시줄에 나타남), **우클릭**(또는 Esc·Ctrl+W) 닫기. 설정 > 시스템·캡쳐의 **이미지 띄우기 > 테두리**(기본 켬)를 두면 둥근 검은 테두리를 그림 바깥에 두릅니다(모서리는 그만큼 둥글게 잘림). 키는 설정 > 단축키에서 바꿉니다.
- **마커 모양 번호**: 마커 도구를 고르면(도구 단추·단축키) 오른쪽 패널의 모양 단추에 **1~6** 이 뜨고, 그 숫자 키(숫자판 포함)로 고릅니다(? ! o x ★ 1 순서). Esc·마커 단축키 다시 누르기로 끄며, 다른 키나 마우스를 누르면 번호가 꺼지고 평소처럼 동작합니다. 도구함에서는 뜨지 않습니다.
- **편집 중 색 바꾸기**: 입력 중인 글자, 그린 직후 편집 상태(파란 점선 상자)의 직선·네모·동그라미·화살표·마커, 선택 도구로 선택한 물체(여러 개 가능)가 있을 때 색 패널에서 현재색을 고르면 그 색으로 바뀝니다. 편집·선택 상태는 유지되고 실행 취소할 수 있습니다. 기본 블러와 붙여넣은 그림은 색이 없어 그대로이며(단색 상자는 바뀜), 바탕색 선택과 도구함 불러오기는 기존 물체의 색을 바꾸지 않습니다.
- **글자 붙여넣기(Ctrl+V)**: 클립보드에 글자가 있으면 그림보다 글자를 먼저 붙입니다. 편집 중이 아니면 커서 위치에서 지금 색·굵기의 새 글자로 시작해 편집 상태가 되고(Enter·Esc·클릭으로 확정), 편집 중이면 입력 위치에 끼워 넣습니다.
- **이미지 붙여넣기(Ctrl+V)**: 클립보드의 이미지를 새 창이 아니라 지금 보고 있는 캔버스의 정가운데(선택한 레이어)에 원래 크기로 붙이고 이동 편집 상태(파란 점선 상자)로 둡니다. 상자 안에서 휠 클릭 드래그로 옮기고(좌클릭 드래그로는 옮겨지지 않음), 네 모서리의 둥근 손잡이를 끌면 크기가 바뀌며(기본은 가로세로 비율 유지, Shift 는 자유롭게), 바깥을 클릭하거나 우클릭하면 끝납니다(실행 취소로 되돌릴 수 있고 `.escs` 에 그림도 함께 저장됨). 어디서나 쓰는 전역 붙여넣기(Ctrl+Shift+V)는 예전처럼 새 창에 엽니다.
- **레이저 포인터**(Alt+1, 도구 줄의 `레이저`): 누른 채 움직이면 꼬리(설정 > 일반 > 레이저: `고정색 · 고정 굵기`(적색, 기본) / `현재색 · 고정 굵기` / `현재색 · 현재 굵기`. 번짐 없는 한 색 선, 머리는 굵고 꼬리는 가늘게)가 따라오고 약 1초에 걸쳐 사라집니다(Excalidraw 의 레이저 포인터와 같은 쓰임). 그림으로 남지 않고 실행 취소 기록·저장·복사에도 나가지 않으며, 화면 공유·발표 때 가리키는 용도입니다.
- **도형 굵기 바꾸기**: 직선·네모·동그라미·화살표·마커를 그린 직후 편집 상태(파란 점선 상자)에서 상자 안에 대고 **Shift+휠**을 굴리면 그 도형의 굵기가 바뀝니다(위 = 굵게, 아래 = 가늘게. 마커는 크기). 오른쪽 패널의 굵기도 같은 값으로 따라가고, 연달아 굴린 것은 실행 취소 한 단계로 묶입니다. 상자 밖에서의 Shift+휠은 지금 선택된 굵기만 바꿉니다.
- **격자와 복사·저장·자르기**: 설정의 "복사·저장에 격자의 행 번호·열 글자 띠도 포함"(기본 켬)이 켜져 있으면 범위 격자의 바깥 띠까지 결과 이미지가 넓어집니다. 범위 격자의 글자·띠 크기는 그림에 고정되어 확대·축소를 함께 따릅니다. 화면 자르기를 해도 격자의 칸 위치와 번호는 그대로이고 자른 영역 밖만 잘려 나갑니다.
- **글자 편집 중 새 위치에 쓰기**(설정, 기본 켬): 커서를 편집 상자 밖으로 옮긴 뒤 글자 키를 누르면 지금 글자를 확정하고 커서 위치에 새 글자를 시작합니다. 지우기·방향키·Enter·공백은 지금 글자에 적용됩니다.
- **선 굵기 증가·감소 단축키**: 설정 > 단축키에 항목이 있고 기본은 비어 있습니다(노브 다이얼 등에 지정). 한 번에 Shift+휠 한 칸과 똑같이 바뀝니다.
- **선택**(Tab, 도구 줄 맨 왼쪽, 점선 사각형 아이콘. Tab 은 숫자칸 순환에 쓰이지 않습니다): 범위를 끌어 지정하면 범위에 조금이라도 걸친 그림(여러 층의 보이는 물체, 격자 제외)이 선택되어 파란 점선 상자로 표시됩니다. 선택된 그림의 상자 안에서 **휠 클릭 드래그**로 한꺼번에 옮기고(실행 취소 한 단계), 우클릭(선택을 풀고 지우개로 이어짐)·도구 변경·실행 취소로 선택이 풀립니다. 상자 밖의 휠 클릭은 선택을 풀고 화면 이동입니다.
- **블러(가리기)**(Alt+6, 도구 줄 맨 오른쪽, 물방울 아이콘): **그냥 끌면 기본 블러**(세기 고정의 부드러운 흐림. 글자가 읽히지 않고 역산으로 되살리기는 어렵지만, 짧은 글자는 후보를 같은 방식으로 흐려 대조하면 맞힐 수 있음), **Ctrl 을 누른 채 끌면 현재색 단색 상자**(내용이 남지 않음. 보안이 필요한 항목은 이쪽). **Shift 를 누른 채 끌면** 네모 그리기처럼 시작점을 중심으로 커지는 정사각형이고, **Ctrl+Shift** 는 시작점 중심의 단색 상자입니다. 끄는 동안 지금 어느 쪽인지 그대로 보이고, 마지막으로 보인 모습으로 확정됩니다. 단색 상자는 편집 상태·선택에서 현재색을 바꾸면 색이 바뀝니다. 영역 밖은 그대로이고 굵기와 무관합니다. 바탕 이미지와 아래 층, 먼저 그린 물체가 가려지며 복사·저장에도 같게 나갑니다. 지우개로 영역 안쪽을 건드리면 지워집니다. 블러 도구를 고르면 오른쪽 미리보기에 기본 블러의 모습이 보입니다. `.escs` 파일에는 원본 이미지가 그대로 있으니 남에게 보낼 때는 복사나 PNG/JPG 저장을 쓰십시오.
- **칠판의 가리개**: 가리개의 범위를 정한 순간의 화면(놓을 때, 옮길 때마다 새로)을 찍어 가립니다. 찍는 동안(약 0.1초) 칠판이 잠깐 사라집니다. 그 뒤에 화면이 바뀌면 가리개는 갱신되지 않습니다. 복사·저장의 배경도 그 순간의 화면을 새로 찍습니다(저장은 대화 상자가 뜨기 전). 화면을 찍지 못하면 옛 화면이 나가지 않도록 복사·저장을 하지 않습니다.
- **지우개(우클릭)**: 지금 선택된 레이어의 물체만 지웁니다.
- **볼펜·형광펜 + Shift**: 누르고 그리면 시작점에서 지금 위치까지 반듯한 직선(각도는 자유)으로 그려지고, Ctrl+Shift 로 그리면 15° 단위로 맞춰집니다.
- **마커 다음 숫자 입력칸**(오른쪽 패널): `< 숫자 >` 모양이고, 칸 위에서 휠을 굴리면 숫자가 바뀝니다(위 = 증가). < > 단추나 직접 입력(Enter)도 됩니다.
- **마커**: 클릭하면 원 안에 숫자(찍을 때마다 +1)가 있는 원이 찍히고, **머리 바깥쪽으로 끌면** 그 방향으로 뭉툭한 꼬리(지도 핀 모양)가 생깁니다. 편집 상태의 방향 손잡이를 끌어 꼬리를 만들거나 없앨 수도 있습니다. Shift+휠은 다른 도구와 같이 굵기·크기(마커는 크기)입니다. ? ! o x ★ 는 패널의 모양 버튼으로 고릅니다.
- 선·네모·동그라미·화살표도 그린 직후에 같은 점선 상자가 나타나 휠 클릭 드래그로 옮길 수 있습니다(설정 > 일반 > 편집에서 끌 수 있고 기본은 켬). 선·화살표는 편집 중에 양 끝에 둥근 이동점이 생기며, 좌클릭으로 끌면 길이·방향이 바뀝니다(Shift = 15° 단위). 큰 도형 상자 안에서 새 도형을 시작하면 편집이 끝나고 그려집니다.
- 마커를 찍은 직후에는 휠 클릭 드래그로 그 마커를 옮길 수 있습니다(마커 둘레에 파란 점선 상자가 보이는 동안). 우클릭은 삭제가 아니라 편집 완료이고, 상자 밖을 클릭하거나 도구를 바꾸면 편집이 끝납니다. 이동은 상자 안에서 휠 클릭 드래그할 때만이고, 상자 밖에서 휠 클릭 드래그하면 화면(그림 전체)이 이동합니다.
- **글자**: Ctrl/Alt 없이 일반 키를 누르면 마우스 위치에서 바로 입력(한글 가능, Backspace/Enter), 마우스를 누르거나 Esc 로 확정. 글자 크기는 선 굵기에 비례합니다.
- **자르기**(Ctrl+6): 드래그로 영역을 만들면 8개 핸들이 생깁니다(핸들=크기 조절, 안쪽 끌기=이동, 새 곳 끌기=다시 선택). Esc = 선택 취소(우클릭은 선택을 취소하고 지우개로 이어짐), 휠 클릭 = 그 영역으로 잘라 0번 층 이미지를 대체합니다(이전/다음으로 되돌림). 0번 층에 그린 것은 이미지에 합쳐지고 위층 그림은 유지됩니다.
- **색 번호 선택**: 오른쪽 패널의 색 제목(팔레트 아이콘)은 도구 줄 표시 설정이 `이름`이면 `색`, `단축키`면 `Ctrl+D ⋅ Ctrl+F`(지정한 키)로 보입니다. Ctrl+D 를 누르면 오른쪽 팔레트의 앞 9색(빨강~갈색)에, Ctrl+F 를 누르면 검정부터 9색(검정~연보라)에 1~9 가 뜹니다. 숫자(위쪽 줄 또는 숫자패드)를 누르면 그 칸을 누른 것과 같이 색이 선택되고 번호는 사라집니다. 같은 단축키를 다시 누르거나 Esc·마우스 클릭·다른 키로 취소합니다. 설정 > 단축키에서 바꿀 수 있습니다. 오른쪽 패널을 숨긴 상태에서는 번호가 보이지 않습니다.
- **창 닫기**: Ctrl+W. 화면 맞춤 Alt+3, 격자 Alt+4(다른 도구처럼 선택 상태가 파랗게 표시되고, 선택돼 있는 동안 범위를 끌 때마다 그 범위 안에만 격자 층이 하나씩 생김. **Shift** 를 누른 채 끌면 가장자리에 잘린 칸이 남지 않게 끄는 방향으로 범위를 늘려 꽉 찬 칸만 만듦. 행열 모양의 행 번호 띠는 범위 바깥 왼쪽, 열 글자 띠는 범위 바깥 위쪽에 붙음. 끌던 중 우클릭·Esc 는 취소, 끌지 않을 때의 우클릭은 지우개), 열기 Ctrl+O(예전 Alt+5 였다가 마커에 양보), 설정 F10.
- **레이어**: 0번(캡처) 위에 `+` 버튼 또는 Ctrl++ 로 1층, 2층… 쌓기. 눈 아이콘으로 켜고 끄기, 클릭하면 그 층에 그림, 더블클릭으로 이름 변경. 왼쪽 손잡이(≡)를 끌어 순서를 바꾸면(놓을 위치가 파란 줄로 표시됨) 목록의 위쪽 층이 캔버스에서 위에 그려집니다(캡처 층도 옮길 수 있음). 오른쪽 ✕ 로 삭제(캡처 층은 삭제 불가, 그림이 있으면 확인 창, 삭제하면 이전/다음 기록이 비워짐). 복사·PNG 저장은 켜 둔 층만 목록 순서대로 합칩니다.
- **새 문서의 레이어**: 캡처·붙여넣기·이미지 파일로 열면 `0번(캡처)` 위에 `1층`이 미리 만들어져 선택되어 있어 원본이 아니라 1층에 그려집니다(화이트보드·칠판·`.escs` 열기는 해당 없음). 레이어 단축키(메인 / 서브): 추가 Ctrl+= / Ctrl+J, 선택한 레이어 숨기기·보이기 Ctrl+- / Ctrl+H, 위 레이어 선택 Alt+] / Ctrl+T, 아래 레이어 선택 Alt+[ / Ctrl+G.
- **레이어 추가·격자 추가도 실행 취소 기록에 한 단계로 남습니다**(이전으로 레이어가 사라지고, 다음으로 다시 생김). 레이어를 지우면 그 층을 추가했던 기록은 기록에서 빠집니다.
- **레이어 순서 이동**: 선택된 레이어를 Ctrl+]는 위로, Ctrl+[는 아래로 한 칸 옮깁니다(설정 > 단축키에서 변경). 끝에 닿으면 움직이지 않습니다(격자 층과는 자리를 바꿀 수 있음). 선택 자체를 바꾸는 키는 Alt+](위 레이어)·Alt+[(아래 레이어)입니다(격자 층은 건너뜀).
- **격자**(Alt+4): 누를 때마다 **지금 선택된 레이어 바로 위에 `격자` 레이어가 하나 추가**됩니다(선택은 그대로, 지우려면 레이어 목록의 ✕). 다른 층처럼 눈 아이콘과 ≡ 로 순서를 바꿀 수 있습니다. 격자 층은 켜 두면 **복사·PNG 저장에도 그려지고**, 그림은 그릴 수 없습니다. 오른쪽 패널 마커 아래의 `격자 모양` 드롭다운으로 **새로 만들 격자**의 모양을 고릅니다(만든 격자는 그 모양으로 고정되고 이후 바꿔도 변하지 않음): ① 격자만 ② 행·열 표시(왼쪽에 1,2,3…, 위에 A,B,C… 엑셀식) ③ 행·열 표시 + 칸마다 좌표(안쪽에 A1, B1 … 열 글자 + 행 번호, 머리글과 같은 번호). 칸은 이미지 기준 px 고정(기본 150, 설정 > 일반 > 격자에서 20~200)이라 확대·축소해도 번호가 바뀌지 않고, 좌표·머리글 글자 크기(10~36, 기본 20)도 같은 곳에서 바꿉니다. **격자의 색은 현재색, 선 굵기는 오른쪽 패널의 굵기**(도형과 같은 그림 기준 px)를 만드는 순간의 값으로 가져오며, 이후 색·굵기를 바꿔도 이미 만든 격자는 그대로입니다(좌표 글자와 머리글도 같은 색). 격자 줄과 좌표는 끌어서 정한 범위 안에만 그립니다. 너무 작아지면 글자·줄만 생략됩니다. 칸 번호는 캡처 이미지 왼쪽 위에서 세고, 불러온 이미지가 없는 문서(화이트보드·칠판)는 격자를 만들 때 보고 있던 캔버스 화면의 왼쪽 위에서 셉니다. `.escs` 에는 층과 모양이 저장됩니다.
- **도구함 줄**: 번호 좌클릭 = 도구·색·굵기 불러오기, 휠 클릭 = 현재 설정 저장(**마커 도구**로 저장하면 다음에 찍힐 숫자·모양도 함께 저장돼 불러올 때 그 값부터 찍힘. 다른 도구의 도구함은 마커 번호를 바꾸지 않음), 더블클릭 = 이름 편집(비우면 번호로 표시), 우클릭 = 삭제, `+` = 새 칸. 앞에서부터 단축키 F1~F4 로 불러옵니다(설정 > 단축키에서 변경). 5번째 도구함부터는 추가될 때 단축키 설정에 항목이 나타나며 기본값은 비어 있습니다.
- **저장**: 이미지 파일(PNG 기본·JPG(품질은 설정 > 시스템·캡쳐 > 저장, 기본 95), 보이는 화면) 또는 `.escs`(레이어·자르기 포함). **파일이 정해진 문서**(불러왔거나 한 번 저장함)는 저장(Ctrl+S)이 **묻지 않고 그 파일에 덮어쓰며**, 옆의 **새로 저장**(Alt+S)이 새 파일 이름을 받아 지금 파일을 두고 저장합니다(이후의 저장은 새 파일에 이어짐). 아직 저장한 적 없는 캡처·붙여넣기·화이트보드·칠판은 새로 저장 단추가 숨고 저장이 새 파일 이름을 묻습니다(Alt+S 도 동작). 저장하고 나면 단추가 나타납니다. **`.escs` 에는 레이어·물체·자르기와 함께 이전/다음 기록(번호 위치 포함), 핀, 다음 마커 숫자까지 저장**되어, 다시 열면 이어서 되돌리고 다시 실행할 수 있습니다(지운 그림도 기록에 남아 파일에 들어갑니다. 남에게 보낼 때는 PNG·JPG 로 저장하거나 복사하십시오. 화면 자르기로 잘라낸 부분도 남습니다). PNG·JPG 에 덮어쓰면 보이는 화면 한 장이 되어 레이어·투명·사진 정보는 남지 않습니다. bmp·gif·webp 로 연 것은 덮어쓰지 않고 새 파일 이름을 묻습니다. **열기**(Ctrl+O): 이미지·.escs. 캡처 메뉴의 **F2 불러오기**(5 칠판 오른쪽)로도 편집창을 열지 않고 바로 파일을 불러옵니다. **붙여넣기**(Ctrl+V / 트레이 메뉴): 클립보드 이미지로 바로 편집.
- **도구 줄 표시 내용**(설정 > 일반): 편집창 위쪽 단추의 글자를 `이름`(기본) 또는 `단축키`로 보여 줍니다. 단축키가 비어 있는 단추는 이름으로 보입니다. 저장하면 열린 편집창에도 바로 적용됩니다.
- **설정 > 일반 탭**: 화이트보드 바탕(테마색 / 검정 #121212 / 흰색 / 사용자 지정: 옆의 색 칸의 색을 씀, 색 칸을 누르면 색 선택 창)과 글자·마커 숫자에 쓰는 글꼴을 고릅니다(저장하면 열린 편집창에도 바로 적용).
- **x초 후 전체화면**(캡쳐 메뉴 `7`): 메뉴를 닫고 설정한 시간(1~30초, 기본 3초)이 지난 뒤 **그 시점에 커서가 있는 모니터**를 캡쳐합니다. 그동안 다른 창을 자유롭게 다룰 수 있고, 결과 처리(클립보드 / 편집창 열기)는 일반 캡쳐와 같습니다. 카운트다운 표시와 중간 취소는 없습니다.
- **캡쳐 소리**: 찰칵 소리를 일반 캡쳐(기본 끔)와 x초 후 캡쳐(기본 켬)에 따로 켜고 끕니다. 편집창에서 보이는 화면 전체를 복사할 때(Ctrl+C·복사 버튼)의 소리는 같은 곳에서 따로 켭니다(**기본 끔**, 선택한 물체·글자 복사에는 나지 않음). 소리 크기는 설정 > 시스템·캡쳐 > 캡쳐의 **소리 크기** 슬라이더(0~100%, 기본 100%)로 줄이며, **들어보기**로 저장 전에 확인합니다.
- **설정에 기본값 표시**(설정 > 시스템·캡쳐 맨 위, 기본 끔): 켜면 일반·시스템·캡쳐·단축키 탭의 항목 이름 옆에 `(B: 기본값)`이 보입니다. 켜고 끄는 항목은 `☑️`(기본 켬)·`🔲`(기본 끔)에 항목의 첫 글자를 붙이고, 긴 선택지는 첫 단어만 적습니다. 체크하면 바로 보이고, 다음에도 보이게 하려면 `저장`을 누릅니다.
- **설정 > 시스템·캡쳐 탭**: 캡쳐(지연 시간·소리), 테마(라이트=밝은 Fluent 모양의 둥근 단추·입력칸 / 다크 / 시스템 설정 따르기, 다크의 화이트보드 바탕은 #121212. 기본은 시스템 설정 따르기), 캡처 후 알림, Windows 시작 시 자동 실행.
- **동그라미·네모**: Shift+끌기는 시작점을 중심으로 커지는 정원 / 정사각형입니다(동그라미는 끄는 거리 = 반지름, 네모는 가로·세로 중 큰 쪽 = 한 변의 절반).
- **설정 > 단축키 탭**: 모든 동작에 메인·서브 단축키를 지정합니다. 다른 동작이 쓰는 키를 넣으면 어디서 쓰는지 한 번 알려 주고, **저장은 막지 않습니다**(쓰이는 상황이 다르면 함께 써도 됨. 같은 화면에서 겹치면 하나만 실행). Tab·Shift+Tab 도 키로 지정되며 Tab 으로 칸을 옮기지 않습니다. 키는 `5`, `=`, `]`, `NumPlus` 처럼 읽기 쉬운 표기로 보입니다. 키 칸을 **우클릭하면 `기본값으로 (…)`** 가 나와 그 칸만 기본 키로 되돌립니다(저장해야 적용). 키 칸 오른쪽 ✕ 버튼으로 비웁니다(Backspace·Delete 는 비우기가 아니라 그 키 자체로 지정됩니다).

## 알려진 시험 필요 사항 (다른 언어 입력)
글자 도구는 화면 밖의 숨은 입력칸(TextBox)으로 입력을 받고 글자 모양은 캔버스에 직접 그립니다. 그래서 **캐럿(깜빡이는 편집선)과 범위 선택 띠는 입력칸이 알려 주는 커서 위치·선택 범위를 읽어 직접 그립니다**(`EditorWindow.cs` 의 `CaretPos`/`SelLen`, `CanvasView.UpdateCaret`).
- **한글**: 조합 중인 글자를 입력칸이 "선택 범위"로 알려 오므로, 조합 중에는 선택 띠를 그리지 않고 캐럿을 조합 글자 뒤에 둡니다. 실제 입력으로 확인했습니다.
- **일본어·중국어 등 조합이 있는 언어는 아직 시험하지 못했습니다.** 조합 중 캐럿 위치, 선택 띠가 조합 글자에 잘못 나오는지, 변환 후보 선택 중 표시, 조합 확정·취소 뒤 상태가 한글과 같게 동작하는지 **입력기를 직접 써 보고 확인해야 합니다.** 조합 중 캐럿은 입력기별 표현 차이에 대비해 "입력칸 커서 위치"와 "선택 시작 + 조합 글자 수" 중 뒤쪽 값을 쓰지만 이는 예상일 뿐입니다.
- 조합이 없는 언어(영어 등)는 글자가 바로 확정되어 해당하지 않습니다.
- 조합 상태 판단은 `TextCompositionManager` 의 조합 시작·갱신·확정 알림에 기대고 있습니다(공식 문서에는 이 알림들의 순서·취소 동작이 적혀 있지 않아, 실제 동작으로 확인한 부분입니다).

## 성능·안정성 메모
- 펜·도형의 영역(Bounds)은 점 개수·굵기가 같으면 캐시를 쓴다(지우개와 화면 밖 걸러내기가 매번 점 전체를 훑지 않게).
- 펜 굵기처럼 연달아 바뀌는 설정은 0.5초 뒤 한 번 저장하고, 프로그램을 끝낼 때 남은 저장을 마친다.
- 편집창을 닫으면 화면 캐시·실행 취소 기록 안의 큰 이미지까지 바로 해제한다.
- `.escs`·이미지를 열 때 상한(JSON 256MB, 이미지 파일 1GB, 이미지 한 장 1.5억 픽셀·문서 전체 3억 픽셀, 물체 500만 개, 레이어 1000개, 글자 10만 자)을 두고, 압축 항목은 머리에 적힌 크기를 믿지 않고 실제로 풀려 나온 양으로 끊는다. 좌표·굵기·종류가 정상 범위가 아닌 물체는 건너뛴다. 클립보드 이미지는 1억 픽셀까지만 받는다.

## 설정 / 로그
`%AppData%\ESCaptureSketch\settings.json`, `log.txt` (환경 변수 `ESCAPTURESKETCH_DATA_DIR` 로 폴더 변경).
단축키는 설정 창에서 바꿉니다 (`Keys`=메인, `Keys2`=서브).
**.escs 파일 연결**: 설정 > 시스템·캡쳐 > 파일 연결(기본 켬)로 켜고 끕니다. 켜면 탐색기에서 `.escs` 파일이 앱 아이콘으로 보이고, 두 번 누르면 열립니다(떠 있으면 그 인스턴스에서). 현재 사용자의 `HKCU\Software\Classes` 에만 등록합니다. 폴더를 지우거나 옮겼다면 앱 폴더의 `ESCaptureSketch-RemoveFileType.bat` 으로 지웁니다(앱 exe 없이도 동작). 다른 프로그램을 연결 프로그램으로 직접 고른 적이 있으면 Windows 가 그 선택을 우선합니다.

**자동 시작**: 설정 > 시스템·캡쳐 > 시작의 체크로 켜고 끕니다(설정 파일이 없는 첫 실행에 한 번 묻고, `자동 실행`을 고른 때만 등록합니다. 다시 묻지 않습니다). 켜면 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 의 `ESCaptureSketch` 항목에 실행 파일 경로가 들어갑니다. 폴더를 지우거나 옮겼다면 앱 폴더의 `ESCaptureSketch-RemoveAutostart.bat` 으로 항목을 지웁니다(앱 exe 없이도 동작). 시험용 이름은 환경 변수 `ESCAPTURESKETCH_AUTOSTART_NAME`.

## 보안 (2026-11-28 점검)

- 네트워크 통신이 없고, 레지스트리는 현재 사용자만, 관리자 권한을 쓰지 않습니다.
- `.escs`·클립보드 자료는 크기·개수·값·기록 번호를 검사합니다. 손상·조작 파일 6,000개 무작위 시험에서 연 뒤의 오류는 없었습니다. 아주 큰 좌표가 들어 있는 파일은 그리기가 몇 초 느려질 수 있습니다.
- 이미지 해석은 SkiaSharp 에 맡깁니다. 취약점 알림이 나오면 패키지를 올립니다.
- 같은 사용자의 다른 프로그램은 실행 중인 앱에 종료·캐처·파일 열기 신호를 보낼 수 있습니다(권한이 같아 막지 않습니다).
- `.escs` 에는 지우거나 잘라낸 내용이 기록으로 남습니다. 남에게 보낼 때는 PNG·JPG 를 쓰십시오.

## 개발용 옵션
- `--register`: `.escs` 연결이 있으면 실행 파일 경로를 고치고 종료 (빌드 뒤 자동 실행), `--unregister`: 연결 삭제
- `--exit`: 떠 있는 인스턴스를 종료
- `--dump <png>`: 합성 스트로크 2000개 문서를 내보내 PNG 저장 + 시간 로그
- `--dumpwin <png>`: 같은 문서로 편집창을 띄워 창 내용을 PNG 저장 (제목 표시줄 제외)
- `--overlaytest <폴더>`: 오버레이를 잠깐 띄워 모드 화면을 저장 (사용자 화면이 찍히니 확인 후 지울 것)
- **글자 크기 보정**(설정 > 일반): 글자 크기 = 굵기 + 보정값(기본 +18, 0~60). 바꾸면 이미 쓴 글자에도 적용됩니다.
- `--dumpbg <png>`, `--dumpset <png>`: 편집창/설정 창을 PNG 로 저장
- `--dumpboard <png>`: 칠판을 띄워 선을 그린 뒤 화면에 보이는 모습(투명 합성)을 PNG 로 저장
- `--autostarttest`: 자동 시작 등록 시험. `ESCAPTURESKETCH_AUTOSTART_NAME` 으로 시험용 이름을 준 경우에만 동작
- `--hw`: GPU 렌더링 (비교용)
- 시험용 환경 변수(`--dumpwin` 등과 함께): `ESCAPTURESKETCH_DEBUG_IMG`(이미지 문서), `_WIDTH`(창 폭), `_FULL`(F11 전환), `_PASTE`(붙여넣기), `_LASER`(레이저 꼬리), `_GRID`·`_GRIDSTYLE`·`_GRIDADD`·`_GRIDRANGE`(격자, `_GRIDRANGE` 는 띠 포함 내보내기·자르기 확인), `_THEME`(테마 전환), `_TAB`(설정 탭), `_MAX`(최대화로 닫기), `_DROP`(레이어 끌기 표시)

## 언어

설정 > 시스템·캡쳐 > 언어에서 `시스템`(Windows 표시 언어가 한국어면 한국어, 아니면 영어), `한국어`, `영어`를 고릅니다. 다시 시작하면 적용됩니다.

- 소스의 한국어 원문이 열쇠이고 영어는 `Strings.En.cs` 에 있습니다. 화면에 새 문구를 넣을 때는 `L.T("원문")`(값이 끼면 `L.F("원문 {0}", 값)`)로 쓰고 영어를 추가합니다. 없으면 한국어로 보입니다.
- 설명서는 `Manual.txt`(한국어, `설명서.txt` 로 동봉)와 `Manual.en.txt`(영어, `manual-en.txt` 로 동봉)를 함께 고칩니다.
